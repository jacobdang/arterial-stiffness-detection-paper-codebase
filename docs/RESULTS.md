# Aggregate results

| Directory | Study content |
|---|---|
| `results/architecture_comparison/` | Supplementary backbone, stream, and computational-efficiency comparisons |
| `results/figure5/` | Retinal-structure associations: 45 odds ratios, confidence intervals, and adjusted P values |
| `results/vessel_pairwise_associations/` | Vessel-feature correlations with the image score and pulse-wave velocity |
| `results/frozen_representation/` | Frozen-feature probe results for 27 vessel measurements and three predictor sets |
| `results/shap_20mi/` | Global SHAP importance across 20 imputation-specific fusion models |
| `results/clinical_utility/` | Screening-cost calculations and net benefit at a decision threshold of 0.20 |

These files contain aggregate statistics. The manuscript and supplement provide the clinical definitions and interpretation. Frozen-feature probes assess information associated with the image representation; they do not establish causal mechanisms. Screening costs use nominal 2014 CNY, a baPWV test cost of CNY 120, and zero incremental fundus-imaging cost for the primary scenario.
