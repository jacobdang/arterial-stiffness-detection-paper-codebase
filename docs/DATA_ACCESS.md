# Data access

Hospital policy does not permit public release of participant-level clinical data, retinal images, or linked predictions. Requests for access may be considered by the corresponding author, Yifei Zhang (zyf11192@rjh.com.cn), subject to institutional review and approval.

The repository includes analysis code, selected model weights, aggregate tables, and synthetic examples. Example images are generated patterns and contain no patient data. Paths under `AUTHORIZED_DATA/` refer to inputs held within an approved local environment. Participant-level files produced by analysis scripts should remain in that environment.
