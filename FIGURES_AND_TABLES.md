# Figure and table source guide

Use this page to locate every main and supplementary figure/table: **6 main figures, 3 main tables, 8 supplementary figures, and 20 supplementary tables**. Paths are relative to this repository. The same index is available as [CSV](paper_index.csv) and [JSON](paper_index.json).

- **Reported tables** preserve the text and display precision of the final manuscript and supplement. Multirow headings and blank merged cells are retained.
- **Analysis results** provide aggregate numerical outputs at their stored precision. They contain no participant-level clinical records or linked predictions.
- **Code** links identify the training, analysis, plotting, or supporting implementation. The scope column explains which role applies.
- **Models** lists the related files included in this release. Image weights are individual TinyNet-C checkpoints (epochs 14 and 19); fusion coefficients represent 20 imputation-specific logistic models. Study analyses use their matching participant predictions and model outputs.

Training and testing commands are in [TRAINING_AND_TESTING](docs/TRAINING_AND_TESTING.md), structural/architecture experiments in [ABLATION](docs/ABLATION.md), and analysis commands in [STATISTICAL_ANALYSIS](docs/STATISTICAL_ANALYSIS.md).

```bash
python scripts/paper_index.py --item "Figure 5"
python scripts/paper_index.py --item "Table S13"
python scripts/paper_index.py --verify
```
