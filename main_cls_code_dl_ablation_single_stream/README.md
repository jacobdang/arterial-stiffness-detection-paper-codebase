# Single-eye comparison

This directory contains the image-classification workflow for the single-eye comparison. Configure the local image, split, and output paths through `PWV_IMAGE_ROOT`, `PWV_SPLIT_ROOT`, and `PWV_OUTPUT_ROOT`. The training and evaluation entry points are `train_main.py` and `test_main.py`.

For complete commands, input schemas, and output filenames, see [the workflow guide](../docs/ABLATION.md) and [the figure/table index](../FIGURES_AND_TABLES.md).
